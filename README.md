IKT projekt: autóalkatrész webáruház

🚗 Cigautó Webshop

A Cigautó Webshop egy autóalkatrészek értékesítésére készült weboldal az IKT projektmunkára .

Funkciók:

-Főoldal autómárka-választóval

-Termékek megjelenítése kártyás elrendezésben

-Akciós termékek kiemelése

-Kosár gomb minden terméknél

-Rólunk oldal a csapat bemutatásával

-Reszponzív kialakítás mobil és asztali nézethez

Webshop megtervezése figmában történt.

A projekt nyomon követése és feladatok meghatározása Jira felületen történt.

A projekt készítője: Vázsonyi Balázs
A webáruház felépítése:

fooldal.html--Főoldal(Autómárka választó)

Termékek.html--Termékek oldal(Kártyás elrendezés,Akciós termékek)

rolunk.html--Rólunk oldal(csapat bemutatása)
